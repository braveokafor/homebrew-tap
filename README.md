# Braveokafor Tap

## How do I install these formulae?

`brew install braveokafor/tap/<formula>`

Or `brew tap braveokafor/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "braveokafor/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
